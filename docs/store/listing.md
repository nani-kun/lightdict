## 名称

```
LightDict 轻词典
```

## 简介（Short description，上限 132 字符）

```
划词即查：选中单词看释义与音标，选中句子看翻译，还能把整个外文网页就地翻成简体中文对照。轻量、快速、不打扰。
```

## 详细说明（Detailed description）

```
LightDict 是一个轻量的划词词典扩展。选中就查，不用切页面、不用复制粘贴。

■ 选中单词
弹出卡片：英美音标、按词性分组的中文释义、可展开的英英解释与例句、真人发音、一键加入生词本。

■ 选中句子
弹出中文译文，下面附着原文对照。

■ 整页翻译
点工具栏按钮或按 Alt+T（macOS 上是 ⌥ Option + T），把整个外文网页就地变成简体中文对照：
每段原文下面跟一段译文，字体、字号、颜色、行高都沿用原文——标题还是标题，引用还是斜体。
再按一次恢复原样。
源语言自动识别，英文、日文、韩文、俄文、法文、阿拉伯文……都不用先选语言；
本来就是简体中文的段落原样跳过，繁体中文会一并转成简体。

■ 中译英（默认关闭）
在设置页打开后，选中中文也会响应：中文词给出拼音与英文对应词，中文句子译成英文。

■ 引擎随你挑
翻译、英汉词典、英英词典、中译英、汉英词典共五类，各自独立选择，全部是免登录的公开接口：
Google 翻译、微软翻译、有道翻译、有道词典、有道英英、金山词霸、必应词典、MyMemory、
SimplyTranslate、Free Dictionary、Wiktionary、Datamuse。英英词典默认用有道英英（WordNet
释义），和必应词典一样国内直连；开启自动降级后，某一家挂了会自动换下一家。
卡片底部会标出这次结果实际来自哪些引擎。

■ 不打扰
卡片渲染在 Shadow DOM 内，不受页面样式干扰，也不会污染页面；自动跟随系统深浅色。
触发方式、停留延迟、卡片主题、发音嗓音、例外网站都可以在设置页调。

■ 关于隐私
没有服务器，没有账号，没有埋点。离开你电脑的只有你主动要查的那段文字，
不含页面地址、页面标题或任何身份信息。生词本与查询缓存只存在本机。
完整说明：https://github.com/nani-kun/lightdict/blob/main/PRIVACY.md

开源（MIT）：https://github.com/nani-kun/lightdict
```

## 单一用途说明（Single purpose）

商店要求用一句话说清扩展只做一件事：

```
把用户选中的文本（或当前网页的正文）送到用户自选的公开词典 / 翻译接口，并把结果显示在页面上。
```

## 权限理由（Permission justification）

每一项都要单独填，照抄即可：

**`storage`**

```
保存用户的设置（引擎选择、触发方式、主题、嗓音等）、生词本，以及查询结果的本地缓存。
全部由 Chrome 保管在本机，不上传。
```

**`activeTab`**

```
整页翻译功能需要读取当前标签页的正文并把译文插回去。仅在用户点击工具栏图标或按下快捷键的
那一刻对当前标签页生效，因此安装时不需要向用户索取任何站点的常驻权限。
```

**`host_permissions`（clients5.google.com、translate.googleapis.com、www.bing.com、
cn.bing.com、aidemo.youdao.com、dict.youdao.com、dict-mobile.iciba.com、
api.mymemory.translated.net、simplytranslate.org、api.dictionaryapi.dev、
en.wiktionary.org、api.datamuse.com）**

```
向用户在设置页选定的词典 / 翻译服务发起查询请求。这些域名被逐一列出而非使用通配符，
扩展只能访问这几个站点。用户选哪家，请求就发给哪家。
```

**内容脚本注入 `<all_urls>`**

```
划词查询要在用户浏览的任意网页上监听选区并渲染结果卡片，因此需要在所有页面注入内容脚本。
该脚本只在本地运行：监听选区、渲染卡片、朗读。它自己不发起任何网络请求，
所有请求都由后台 service worker 按上面列出的域名发出。
```

## 数据用途声明（Data usage）

商店的勾选题，按下面填：

- 收集的数据类别：**均不收集**（不收集个人身份信息、健康信息、财务信息、身份验证信息、
  个人通信、位置、网页浏览记录、用户活动、网站内容）
- 三项声明全部勾选「是」：
  - 不将数据出售给第三方，与经核准的用例无关
  - 不将数据用于或转移用于与项目单一用途无关的目的
  - 不将数据用于或转移用于确定信用度或放贷目的
- 隐私政策网址：`https://github.com/nani-kun/lightdict/blob/main/PRIVACY.md`

> 说明：用户选中的文本会发给用户自选的第三方翻译接口，这属于「实现功能所必需的传输」，
> 不构成商店定义的「收集」——扩展本身不留存、不回传给开发者。
> 若审核问及，指向 PRIVACY.md 即可。
