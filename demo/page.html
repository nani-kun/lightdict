What a browser extension actually is

By The Editors · March 4, 2024 · 6 min read

A browser extension is a small software module that customizes the browser. Extensions are built with the same web technologies as ordinary pages — HTML, CSS and JavaScript — but they run with privileges that a page never gets, such as reading data from another origin.

Because an extension lives next to every page you visit, a good one stays out of the way. It should do one thing, do it quickly, and leave the page exactly as it found it.

The best tools disappear. You notice them only when they are missing.

How the pieces fit together

  • The content script runs inside the page and can read or change the DOM.
  • The service worker runs in the background and makes the network requests.
  • The popup and the options page are ordinary pages shipped inside the extension.
