What a browser extension actually is

A browser extension is a small software module that customizes the browser. Extensions are built with the same web technologies as ordinary pages, but they run with privileges that a page never gets.

Because an extension lives next to every page you visit, a good one is resilient and nearly ubiquitous: it should do one thing, do it quickly, and leave the page exactly as it found it.

中文查英文（扩展里默认关着，打开后是这样） 选中弹性这个词，或者整句：今天天气很好，我们出去走走吧。

  • 出得快。意思和音标一般半秒内就到，先查到的先显示，不会让你对着一张空卡片干等。
  • 发音读的是英文那一边。英文词读词本身，中文词读它对应的英文，句子读英文那一句。点音标可以分别听英音和美音。
  • 不弄乱网页。卡片只是浮在上面，页面本身一个字都没被改动，深色浅色也会跟着你的系统走。

整页翻译 · whole page

中文就接在原文下面

不是把你带去另一个页面，而是在每段外文后面补一段中文，字体、字号都随着原文走。

  • 不用挑语言。英文、日文、韩文、法文、俄文都一样，按一下就翻成中文。本来就是中文的段落会跳过去。
  • 版面不会乱。列表还是那么多条，表格还是那么多格，不会翻一次就多出一堆东西。
  • 代码和输入框不碰。正在填的表单、代码块这些地方一律不动。
  • 先翻眼前这一屏。你看到哪儿就先翻哪儿，往下滚会接着翻，刷不到底的页面也跟得上。
  • 不按就不动。只有你点了按钮或按了快捷键，它才开始工作，平时安安静静待着。

隐私 · privacy

我们没有服务器

不用注册账号，不记录你做过什么，也没有一台机器在中间收着你的东西。

  • 只有你要查的那几个字会出去。它们直接发给你选的那家词典，不带网址、不带标题，也不带任何能认出你的信息。
  • 你在看什么，我们不知道。没有账号，没有统计，没有后台。
  • 有一个例外，先说清楚。微软翻译的接口要求带上 bing.com 的 cookie，用它翻译时会一起发出去。介意的话换一家就行。
  • 生词本只存在你的电脑上。查过的结果会在本地留 7 天，省一次网络；设置和生词本都能随时清空。
  • 只要两个权限。一个用来存设置和生词本，一个让整页翻译在你按下按钮时生效。没有别的。

安装 · install

四步，一分钟

下载解压就能装，不用别的准备。Chrome 102 以上的版本都可以，Edge 之类的浏览器也一样。

  1. 下载下面的 ZIP，解压到一个不会被你随手删掉的文件夹。
  2. 在地址栏输入 chrome://extensions/ 打开扩展页，把右上角的开发者模式打开。
  3. 点加载已解压的扩展程序，选中刚才那个文件夹。
  4. 刷新一下网页就能划词了。装好后会自动打开设置页，可以顺手挑挑自己的喜好。
